## Cómo leer este repositorio

- Cada reto tiene su carpeta, un `README.md` y, cuando existen, imágenes de referencia.
- Fuera de la competencia se seleccionaron soluciones documentadas como resueltas; algunas tienen verificación local, no aceptación registrada.
- En CITC 2026 se conserva todo el progreso. Las candidatas rechazadas y las hipótesis no se presentan como soluciones válidas.
- Los prefijos y conversiones MD5 dependen del reto; no se normalizan ni se inventan.
- No se distribuyen ejecutables, volcados, capturas de tráfico, archivos comprimidos ni carpetas de trabajo. Los comandos pueden necesitar los materiales originales del reto.
- El código de apoyo necesario se incluye dentro del texto cuando está disponible.
